# Security policy

## Supported versions

Only the latest version, published on the main branch and the live site, gets security fixes.

## Reporting a problem

Please report security problems privately. Do not open a public issue.

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem and how to reproduce it.

You will get an answer as soon as possible. Please give us reasonable time to fix the problem before you share it publicly.
